# Product Steering

This workspace contains a production-style personal Kanban board.

Prioritize:
- Intentional visual hierarchy and calm interaction design
- Reliable task CRUD and drag-and-drop behavior
- Secure per-user data isolation through Supabase RLS
- Clear loading, empty, validation, and failure states
- Responsive behavior across desktop and mobile
- Maintainable TypeScript and small components

Do not introduce a service-role key, hardcoded secrets, or unnecessary backend complexity.
